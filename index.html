PHP Backend Architecture
This frontend connects to a Laravel 11 REST API. File uploads are parsed by PhpSpreadsheet (Excel) and League/CSV. Statistical computations run in PHP services. Reports are generated as PDFs using DomPDF. All data stored in MySQL 8 with Redis queue for async jobs.
